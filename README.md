# 坦克大战 · Tank Battle

经典《坦克大战》(Battle City) 风格的网页小游戏，纯 **HTML + CSS + JavaScript** 单文件实现，无需任何依赖或构建工具，双击 `index.html` 即可游玩。

## ✨ 特性

- 🎮 经典玩法：驾驶坦克守住基地，消灭一波波敌军
- 🧱 可破坏的砖墙、坚不可摧的钢板（满级火力可击穿）、河流与草丛
- 🤖 三种敌人：普通坦克、快速坦克、装甲坦克（3 点血）
- ⭐ 道具系统：火力升级、护盾、加命、全屏炸弹
- 🔊 基于 Web Audio API 的复古音效
- 📱 支持键盘与移动端虚拟按键
- 🏆 无尽关卡，难度随关卡提升

## 🕹️ 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / `WASD` | 移动坦克 |
| 空格 | 开火 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

移动端会自动显示虚拟方向键与开火按钮。

## 🚀 如何运行

**方式一：直接打开**

双击 `index.html`，或在浏览器中打开该文件即可。

**方式二：本地服务器**

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

**方式三：GitHub Pages**

仓库已可部署为 GitHub Pages（Settings → Pages → Deploy from branch → main）。

## 🎯 游戏规则

- 保卫画面底部的基地（老鹰），**基地被摧毁即游戏结束**（注意不要误伤自己的基地）。
- 消灭当前关卡所有敌人即可进入下一关。
- 玩家有 3 条命，被击中会重置火力等级。
- 部分闪烁的敌人被消灭后会掉落随机道具。
